# 06 — Système Collabs & Collectors

## Principe

Pro.Hibited doit rester collab-friendly dès le départ, sans casser l’équilibrage.

## Séparation importante

### Cartes core

Les cartes canoniques définissent les règles du jeu : Weed, Hash, CBD, Filter, Paper, Fire, BBQ, Bong, Blunt, Smoke Me, Wind, Rain, Cops, Lost.

### Variantes cosmétiques

Une carte peut avoir plusieurs visuels sans changer son effet.

Exemples :

- Smoke Me — Neon Riot Edition
- Lost — Gold Foil Edition
- CBD — Peacekeeper Edition
- Bong — Artist Series

### Cartes gameplay spéciales

À réserver aux modes Chaos, Event ou Custom.

Exemples futurs :

- Fake Fire
- Paranoia
- Munchies
- Rolling Tray
- Stash
- Unexpected Guest

## Raretés proposées

- Core
- Rare
- Collector
- Artist Series
- Collab Edition
- Blacklace Edition
- Event Limited

## Règle d’équilibrage

Aucune collab ne doit rendre Smoke Me trop facile. Le gag central reste : tout le monde essaie, le jeu dit non.

## Types de collaborations possibles

- Illustrateurs
- Street artists
- Tattoo artists
- Marques alternatives
- Grow shops / head shops selon cadre légal
- Streamers
- Univers Blacklace Island
- Éditions événementielles

## Données à prévoir

Chaque carte doit pouvoir stocker :

- cardId
- variantId
- name
- family
- effect
- edition
- artist
- rarity
- cosmeticOnly
- imageUrl
- releaseTag

## Modes compatibles

### Classic
Deck canon uniquement.

### Collector
Deck canon + variantes visuelles.

### Chaos
Cartes spéciales gameplay autorisées.

### Custom Room
Le créateur choisit les extensions actives.

## Règle de marque

Une collab réussie doit enrichir le monde Pro.Hibited, pas simplement coller un logo sur une carte.
