# 04 — Game Design Document V0.2

## Titre

Pro.Hibited Online

## Genre

Party card game multijoueur tour par tour.

## Joueurs

2 à 5 joueurs.

## Plateformes

- Web mobile
- Web desktop
- Prototype local puis multijoueur en rooms privées

## Pitch

Les joueurs tentent de compléter un set interdit. Ils assemblent Produit, accessoires et feu, mais les autres joueurs et le système les sabotent constamment.

> Here, we don’t smoke. It’s Pro.Hibited.

## Conditions de victoire V0

Le premier joueur à valider un set complet avec Smoke Me devient Junky et gagne la manche.

## Setup V0

- 2 à 5 joueurs.
- Chaque joueur commence avec 5 cartes.
- Pioche commune.
- Défausse commune.
- Sens horaire.
- Premier joueur aléatoire.

## Tour de joueur V0

1. Piocher 1 carte.
2. Jouer jusqu’à 2 cartes.
3. Optionnel : faire un don.
4. Finir le tour.
5. Défausser si plus de 7 cartes en main.

## Actions

- Poser une carte sur son set.
- Donner une carte compatible à un autre joueur.
- Attaquer un set adverse.
- Jouer Smoke Me si le set est complet.
- Finir son tour.

## Zones de jeu

- Main du joueur.
- Set en construction.
- Pioche.
- Défausse.
- Log d’événements.
- Badge / statut Junky.

## UX prioritaire

- Le joueur doit comprendre immédiatement pourquoi Smoke Me est verrouillé.
- Les sets adverses doivent être lisibles.
- Les attaques doivent clairement montrer la carte ou le set affecté.
- Le log doit raconter la partie comme une mini-comédie.

## Prototype V0 non inclus

- Comptes utilisateurs.
- Boutique.
- Matchmaking public.
- Classement.
- Chat vocal.
- Cartes collab gameplay.
- IA.

## Critère de réussite du prototype

À la fin du test, les joueurs doivent avoir envie de dire : “Attends, on en refait une.” Pas parce que tout était parfait, mais parce que le sabotage a créé une histoire.
