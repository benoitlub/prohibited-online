# 02 — Moodboard & Direction Artistique

## Intention visuelle

**Pop, interdit, cartoon, faux administratif, chaos de table.**

Le jeu doit donner l’impression d’un vrai deck physique transporté dans une interface numérique vivante. Pas de minimalisme clinique. Pas de casino mobile. On veut du carton, des couleurs, du bruit, des petits drames.

## Règle 70 / 30

- **70 % fidélité au jeu physique** : couleurs franches, cartes lisibles, humour direct, dos de carte symbolique.
- **30 % adaptation digitale** : animations, lisibilité mobile, états interactifs, effets d’attaque, feedback sonore.

## Éléments à préserver

- Le dos Pro.Hibited comme symbole de l’interdiction.
- Les gros noms de cartes.
- Les familles visuelles distinctes.
- Le côté fait-pour-être-joué.
- L’énergie party card game.

## Palette suggérée

- Vert sombre : fond principal, table interdite.
- Vert acide : accent système, validation presque autorisée.
- Rouge prohibition : refus, Cops, danger.
- Jaune / orange : Fire, BBQ, tension.
- Rose / violet : Smoke Me, collector, glitch fun.
- Blanc cassé : lisibilité texte, effet carte imprimée.

## Typographie

### Titres de cartes
Grosse graisse, lisible, cartoon ou affichage publicitaire.

### Interface
Sans-serif propre, très lisible mobile.

### Système Pro.Hibited
Style tampon, panneau interdit, avertissement administratif absurde.

## UI principale

### Mobile
- Haut : adversaires compacts, set visible + nombre de cartes en main.
- Centre : pioche, défausse, log court.
- Bas : set du joueur actif + main scrollable.
- Bouton Smoke Me visible mais verrouillé si non valide.

### Desktop
- Table centrale.
- Joueur local en bas.
- Adversaires autour.
- Log événementiel à droite.
- Zone actions à gauche ou bas.

## Animations clés

- **Wind** : carte secouée, dernière carte aspirée vers la défausse.
- **Rain** : gouttes absurdes, dernière carte glisse et tombe.
- **Cops** : flash rouge/bleu, set Weed/Hash confisqué.
- **Lost** : glitch brutal, set entier avalé par le dos de carte.
- **Smoke Me refusé** : dos de carte plein écran, tampon PRO.HIBITED.
- **Smoke Me validé** : le système tremble, Exception granted, badge Junky.

## Écran de refus canonique

```txt
HERE, WE DON’T SMOKE.
IT’S PRO.HIBITED.
```

Variante courte :

```txt
STILL PRO.HIBITED.
```

## Règle d’or

Chaque effet visuel doit renforcer la méta : le système interdit, les joueurs insistent, le chaos répond.
