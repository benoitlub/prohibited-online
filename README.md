# Pro.Hibited Online — Starter Kit V0.1

Ce dossier pose la base de travail pour transformer Pro.Hibited en jeu de cartes multijoueur web/mobile.

## Contenu

- `docs/01_BIBLE_CREATIVE.md` — ADN du jeu, slogan, méta, ton, principes non négociables.
- `docs/02_MOODBOARD.md` — direction artistique, couleurs, interface, animations, références internes.
- `docs/03_CODEX_CARTES_REGLES.md` — règles canoniques, combos, attaques, statut Junky.
- `docs/04_GDD_V0_2.md` — Game Design Document condensé.
- `docs/05_ARCHITECTURE_TECHNIQUE.md` — architecture prototype local puis multijoueur.
- `docs/06_SYSTEME_COLLABS_COLLECTORS.md` — collaborations, raretés, extensions, skins.
- `docs/07_PARTAGE_SOCIAL_HUMOUR.md` — phrases in-game, résultats partageables, succès.
- `docs/08_PROMPT_PROTOTYPE.md` — prompt prêt à donner à Lovable, Cursor, Claude Code ou Replit.
- `data/cards.json` — base de données cartes en JSON.
- `data/event_lines_fr.json` — lignes d’événements humoristiques.
- `notion_import/*.csv` — tables prêtes à importer dans Notion.
- `src/game/*` — squelette TypeScript du moteur de jeu.
- `assets/references/` — images de référence des cartes fournies.

## Philosophie

Pro.Hibited Online n’est pas un jeu où l’on fume. C’est un jeu où tout le monde tente de compléter un set interdit pendant que le système et les autres joueurs répondent : non.

> HERE, WE DON’T SMOKE. IT’S PRO.HIBITED.

## Prochaine étape

1. Créer un prototype React + Vite + TypeScript.
2. Implémenter le moteur local avant le multijoueur.
3. Tester la sensation : construire, se faire saboter, rire/rager, recommencer.
