# 07 — Partage Social & Humour In-Game

## Objectif

Transformer les moments de sabotage en souvenirs partageables.

Pro.Hibited doit produire des captures que les joueurs ont envie d’envoyer à leurs amis : refus de Smoke Me, set détruit par Lost, intervention des Cops, victoire Junky improbable.

## Ton

Potache, absurde, insolent, mais pas lourd. Le gag principal n’est pas la consommation : c’est l’interdiction permanente et la mauvaise foi autour de la table.

## Messages système

### Smoke refusé

- HERE, WE DON’T SMOKE. IT’S PRO.HIBITED.
- Still Pro.Hibited.
- Nice try. The table says no.
- Smoking attempt denied by cardboard authority.

### Smoke validé

- Exception granted. You became Junky.
- The system looked away for one second.
- Prohibition breached. Junky unlocked.

### Wind

- A tragic breeze entered the chat.
- Wind removed the last card. Nature has opinions.

### Rain

- Rain washed away the last hope.
- Fire met weather. Weather won.

### Cops

- Cops found contraband. The whole set left quietly.
- CBD showed paperwork. Cops moved on.

### Lost

- Lost swallowed the entire set. No witnesses.
- The set has left the dimension.

## Cartes de résultat partageables

À la fin d’une manche, générer une image ou fiche :

- gagnant ;
- statut Junky ;
- nombre de sets détruits ;
- nombre d’attaques subies ;
- nombre de Smoke Me refusés ;
- meilleure humiliation.

## Succès possibles

- Still Pro.Hibited — tentative refusée.
- Cops Magnet — 3 sets confisqués.
- Lost Again — perdre un set complet.
- Weather Victim — subir Wind et Rain dans la même manche.
- CBD Bureaucrat — survivre à Cops avec CBD.
- Junky Unlocked — première validation.

## Partage externe

Prévoir plus tard :

- image PNG de fin de partie ;
- lien replay léger ;
- GIF d’un moment clé ;
- carte profil joueur ;
- citation automatique.

## Règle d’or

Le partage doit célébrer la catastrophe. Dans Pro.Hibited, perdre avec panache vaut presque autant que gagner.
