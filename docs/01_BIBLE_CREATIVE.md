# 01 — Bible créative Pro.Hibited Online

## Logline

**Pro.Hibited Online** est un party card game de sabotage où les joueurs tentent de compléter un set interdit. Le but apparent est de fumer, mais la mécanique du jeu repose sur l’impossibilité presque permanente d’y parvenir.

## Slogan canonique

> **Here, we don’t smoke. It’s Pro.Hibited.**

Version française possible :

> **Ici, on ne fume pas. C’est Pro.Hibited.**

## La méta

Pro.Hibited n’est pas une apologie. C’est un gag systémique : tous les éléments d’un joint sont là, mais le jeu est construit pour empêcher la validation. Le joueur ne “fume” pas vraiment ; il tente de contourner l’interdiction.

Le dos de carte incarne cette interdiction. Dans le jeu physique, montrer le dos de la carte en disant “c’est interdit de fumer” devient, dans la version numérique, un vrai moment d’interface : animation de refus, écran de blocage, tampon système.

## Boucle émotionnelle

1. Je construis.
2. Je crois tenir le bon combo.
3. Quelqu’un me sabote.
4. Le jeu me rappelle que c’est interdit.
5. Je râle, je ris, je recommence.
6. Si je réussis, ce n’est pas une consommation : c’est une exception, une faille, une transgression ludique.

## Piliers de design

### Interdiction active
Le jeu doit constamment rappeler que valider est difficile. Smoke Me doit rester rare, désiré, protégé et maudit.

### Sabotage joyeux
Les attaques ne sont pas accessoires. Wind, Rain, Cops et Lost sont les gardiens du concept.

### Lisibilité immédiate
Chaque carte doit être comprise en une seconde. Nom fort, famille claire, effet simple.

### Humour potache mais intelligent
Le jeu peut être insolent, absurde et parfois débile, mais il ne doit pas devenir lourd. La bonne cible de la blague est le système d’interdiction, la malchance et la mauvaise foi entre amis.

### Fidélité au jeu physique
Les cartes originales sont le socle canonique. Le digital les remasterise, il ne les efface pas.

## Ce que le jeu n’est pas

- Un simulateur de consommation.
- Un jeu réaliste.
- Un jeu compétitif froid.
- Une interface poker générique avec des feuilles vertes collées dessus.

## Ce que le jeu est

- Un jeu de table numérique.
- Un théâtre de sabotage.
- Une blague sur l’interdiction.
- Une machine à moments partageables.
- Un support naturel pour collabs, skins et éditions limitées.

## Phrase de direction

Si une idée rend la validation trop facile, elle trahit Pro.Hibited. Si une idée rend l’échec plus drôle, elle est probablement bonne.
